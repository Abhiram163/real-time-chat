# Real-Time Chat Application

A full-stack real-time messaging application built with **React, Node.js, Express, and Socket.IO**. The application provides instant messaging, user authentication, responsive design, and real-time communication between users.

## Features

- **Real-Time Messaging** — Instant message delivery using Socket.IO.
- **User Authentication** — User registration, login, and session handling.
- **Online Presence** — Real-time updates for user availability.
- **Responsive Design** — Mobile, tablet, and desktop support using Tailwind CSS.
- **REST API Communication** — Axios-based communication between frontend and backend.
- **Component-Based UI** — Reusable React components for a maintainable frontend.

## Tech Stack

### Frontend

- ReactJS
- Tailwind CSS
- React Router DOM
- Axios
- Socket.IO Client

### Backend

- Node.js
- Express.js
- Socket.IO Server
- Js-cookie

## Project Architecture

The application follows a client-server architecture:

- **React frontend** handles the user interface and client-side interactions.
- **Express/Node.js backend** handles API requests and application logic.
- **Socket.IO** enables real-time, bidirectional communication between users.
- **Axios** handles REST API communication between the frontend and backend.
